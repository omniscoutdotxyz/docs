## Installation

**This is the only manual setup you need to do.** After these steps, your AI agent will handle the rest of the OmniScout setup.

Watch the video to learn how.

Or, you can read the following steps. If you have seen the video, you don't need to read this.

Visit [omniscout.xyz](https://omniscout.xyz/).

![The OmniScout website with the Copy Prompt button](/installation-guide/step-1.png)

Click **Copy Prompt**, or select one of the listed AI agents to open the installation prompt in that agent.

![AI agent choices on the OmniScout website](/installation-guide/step-2.png)

- Send the prompt to your AI agent.
- The agent will complete the OmniScout setup. It may ask you to:
  - Select a default browser.
  - Choose between multiple installed browsers.
  - Grant the permissions OmniScout needs.
- When setup is complete, a page will open automatically.

![The OmniScout browser setup page](/installation-guide/step-3.png)

On that page, click **Allow Remote Debugging** to enable browser functionality.

**OmniScout is ready to use with your AI agent.**
