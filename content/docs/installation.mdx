OmniScout lets your AI agent search the web and work with pages in a browser. Start the setup below; your agent will install and configure OmniScout for you.

## Start setup

Visit [omniscout.xyz](https://omniscout.xyz/) and click **Copy Prompt**, or choose your AI agent from the list to open the setup prompt there.

![The OmniScout website with the Copy Prompt button](/installation-guide/step-1.png)

![AI agent choices on the OmniScout website](/installation-guide/step-2.png)

Send the prompt to your agent. During setup, it may ask you to choose a default browser, select one from the browsers on your computer, or approve permissions. Choose the browser you want OmniScout to use and review each permission request before approving it.

## Enable browser access

When setup is complete, a page opens automatically. Click **Allow Remote Debugging** on that page to enable OmniScout's browser features.

![The OmniScout browser setup page](/installation-guide/step-3.png)

## Try it with your agent

Once setup is done, ask your agent for the task you want help with. For example:

- “Find three recent articles about [topic] and summarize them with links.”
- “Open [website] and summarize this page.”
- “Compare the details on these pages and tell me what differs.”

If you use a browser where you are signed in, the agent may be able to work with those signed-in pages. Review actions before the agent submits a form, sends a message, or makes a purchase.

That’s it. You can return to this page if you need to set up OmniScout again.
