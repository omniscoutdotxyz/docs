## Установка

**Это единственная настройка, которую нужно выполнить вручную.** После этих шагов ИИ-агент настроит OmniScout самостоятельно.

Откройте [omniscout.xyz](https://omniscout.xyz/).

![Кнопка Copy Prompt на сайте OmniScout](/installation-guide/step-1.png)

Нажмите **Copy Prompt** или выберите одного из ИИ-агентов в списке, чтобы открыть в нём инструкцию по установке.

![Список ИИ-агентов на сайте OmniScout](/installation-guide/step-2.png)

- Отправьте инструкцию своему ИИ-агенту.
- Агент настроит OmniScout. Он может попросить вас:
  - Выбрать браузер по умолчанию.
  - Выбрать один из установленных браузеров.
  - Разрешить OmniScout необходимые права.
- После завершения настройки страница откроется автоматически.

![Страница настройки браузера OmniScout](/installation-guide/step-3.png)

На этой странице нажмите **Allow Remote Debugging**, чтобы включить работу с браузером.

**Теперь OmniScout готов к работе с вашим ИИ-агентом.**
