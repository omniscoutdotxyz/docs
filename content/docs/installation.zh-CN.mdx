OmniScout 可以帮助 AI agent 搜索网页并在浏览器中操作页面。按下面的步骤开始设置，agent 会为你安装并配置 OmniScout。

## 开始设置

访问 [omniscout.xyz](https://omniscout.xyz/)，点击 **Copy Prompt**，或从列表中选择你的 AI agent，在对应工具中打开设置提示。

![OmniScout 网站上的 Copy Prompt 按钮](/installation-guide/step-1.png)

![OmniScout 网站上的 AI agent 选项](/installation-guide/step-2.png)

将提示发送给 agent。设置过程中，agent 可能会让你选择默认浏览器、从电脑上已安装的浏览器中选择一个，或批准所需权限。请选择你希望 OmniScout 使用的浏览器，并在批准前确认每项权限请求。

## 开启浏览器访问

设置完成后，页面会自动打开。点击页面上的 **Allow Remote Debugging**，即可启用 OmniScout 的浏览器功能。

![OmniScout 浏览器设置页面](/installation-guide/step-3.png)

## 试着向 agent 提出请求

设置完成后，直接告诉 agent 你想做什么。例如：

- “查找三篇近期关于[主题]的文章，并附链接总结。”
- “打开[网站]并总结这个页面。”
- “比较这些页面上的信息，并告诉我有哪些不同。”

如果你选择了已登录账号的浏览器，agent 可能可以访问登录后的页面。在提交表单、发送消息或购买之前，请先检查内容。

设置完成。下次需要重新设置时，可以回到本页。
