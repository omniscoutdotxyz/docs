## 安装

**你只需手动完成这一步。** 完成后，AI agent 会继续设置 OmniScout。

访问 [omniscout.xyz](https://omniscout.xyz/)。

![OmniScout 网站上的 Copy Prompt 按钮](/installation-guide/step-1.png)

点击 **Copy Prompt**，或从列表中选择一个 AI agent，在对应工具中打开安装提示。

![OmniScout 网站上的 AI agent 选项](/installation-guide/step-2.png)

- 将提示发送给你的 AI agent。
- agent 会完成 OmniScout 的设置。过程中可能会询问你：
  - 选择默认浏览器。
  - 从已安装的浏览器中选择一个。
  - 授予 OmniScout 所需的权限。
- 设置完成后，页面会自动打开。

![OmniScout 浏览器设置页面](/installation-guide/step-3.png)

在该页面点击 **Allow Remote Debugging**，启用浏览器功能。

**现在可以通过 AI agent 使用 OmniScout 了。**
