OmniScout를 사용하면 AI 에이전트가 웹을 검색하고 브라우저에서 페이지를 다룰 수 있습니다. 아래 설정을 시작하면 에이전트가 OmniScout 설치와 구성을 진행합니다.

## 설정 시작하기

[omniscout.xyz](https://omniscout.xyz/)에 방문해 **Copy Prompt**를 클릭하거나 목록에서 AI 에이전트를 선택해 설정 프롬프트를 엽니다.

![OmniScout 웹사이트의 Copy Prompt 버튼](/installation-guide/step-1.png)

![OmniScout 웹사이트의 AI 에이전트 선택 항목](/installation-guide/step-2.png)

프롬프트를 에이전트에 보내세요. 설정 중 기본 브라우저나 컴퓨터에 설치된 브라우저를 선택하고 권한을 허용하라는 요청을 받을 수 있습니다. 사용할 브라우저를 선택하고 각 권한 요청을 확인한 뒤 허용하세요.

## 브라우저 접근 허용하기

설정이 끝나면 페이지가 자동으로 열립니다. OmniScout의 브라우저 기능을 사용하려면 해당 페이지에서 **Allow Remote Debugging**을 클릭하세요.

![OmniScout 브라우저 설정 페이지](/installation-guide/step-3.png)

## 에이전트에게 요청하기

설정이 끝나면 원하는 작업을 에이전트에게 요청하세요. 예를 들면:

- “[주제]에 관한 최신 기사 3개를 찾아 링크와 함께 요약해 줘.”
- “[웹사이트]를 열고 페이지 내용을 요약해 줘.”
- “이 페이지들의 정보를 비교하고 차이점을 알려 줘.”

로그인된 브라우저를 선택하면 에이전트가 로그인 후 페이지에서 작업할 수도 있습니다. 양식 제출, 메시지 전송, 구매 전에는 내용을 직접 확인하세요.

이제 준비가 끝났습니다. 다시 설정해야 할 때 이 페이지를 참고하세요.
